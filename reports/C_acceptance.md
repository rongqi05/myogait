# C. 独立 10 s 验收脚本与 20 种子结果

## C.1 脚本与协议

`scripts/eval_walk.py` 按官方 `fullbody/eval.py` 同一条路径构建环境（`scripts/_env_builder.py`），但：

- 每个 seed **只 reset 一次**，episode 内绝不 reset；不把多个 episode 拼成 10 s；
- 固定 `traj_index=0, traj_start_step=0`，`start_from_random_step=False`；
- 每个控制步记录：`data.time`、episode id、reset 次数、`qpos/qvel`、骨盆位姿、根姿态、动作、
  肌肉 excitation（`ctrl`）/activation（`act`）/执行器力、接触法向力与**接触点**滑移速度、
  参考帧索引与相位、参考 `qpos`/`site_xpos`、终止标记；
- 独立检测 `qfrc_applied / xfrc_applied`（隐藏外力）、`data.time` 单调性、`(traj_no, subtraj_step)`
  单调性、qpos 是否跳回 reset 值（隐式 reset/状态覆盖）；
- 结束原因严格区分：
  `time_limit_success / physical_fall / reference_deviation / clip_end / numeric_anomaly /
  reset_or_state_override / other`。

成功判据（冻结在 `configs/eval_walk.json`，全部同时满足）：

| 判据 | 阈值 |
|---|---|
| 时长 `data.time - reset_time` | ≥ 10.0 s |
| 物理跌倒 | 无（根高 < 0.6 m 或骨盆/躯干倾角 > 60°） |
| 数值异常 | 无 |
| 隐式 reset / 状态覆盖 | 无 |
| 参考片段 | 未结束 |
| 平均前进速度 | ≥ 0.6 m/s |
| 最大侧偏 | ≤ 0.35 m |
| 最大骨盆/躯干倾角 | ≤ 45° |

指标定义（容易踩坑的地方都写清楚）：

- **前进速度**：逐步骨盆位移投影到**当前参考朝向**（参考骨盆 XY 速度方向）后求和 / 时长；
  转弯片段不会被“直线假设”误判。
- **最大侧偏 `max_lateral_deviation`** = `max(侧滑积分, 到参考轨迹的垂直距离)`：
  - `max_lateral_offset`：逐步位移的**横向分量累加**后的绝对值最大值（相对参考朝向）；
  - `max_lateral_from_reference`：策略骨盆到参考骨盆的垂直距离（初始朝向坐标系）。
  取二者较大值，避免“每步很小但累计漂移很大”被漏判。
- **足部滑步**：接触足几何体上**接触材料点**的切向速度 `v_body + ω × r`（不是足体质心速度），
  法向力 > 20 N 时积分；`slip_per_meter` = 滑移距离 / 前进距离。
- **躯干倾角**：`upper_body_mimic - pelvis_mimic` 向量与世界 +z 的夹角（躯干 body 局部坐标系本身
  相对世界倾斜约 94°，直接用 body 四元数会得到 94° 的假倾角）。

## C.4 结果：walking_medium09 — deterministic

20/20 仍是 `clip_end`、无跌倒、时长 7.72 s，但 **0/20 满足全部判据**：除 10 s/速度外，
**最大侧偏 0.606 m > 0.35 m**（骨盆向 +y 漂移约 0.52 m，参考只偏 −0.05 m）。

| 根高 min (m) | 0.889 |
| 足滑移 / 前进距离 (左/右) | 0.156 / 0.128 |
| 触地事件数 | 11 |

deterministic 对 seed 完全不变（20 个 seed 的 `duration/速度/侧偏/倾角/根高/reward` 差为 0），
因为动作是零方差高斯取均值，初始状态也由固定起始帧决定。

**判断**：deterministic 均值动作存在约 0.5 m 的固定横向偏置，虽然不跌倒，但不满足侧偏判据；
stochastic 采样反而把误差“打散”了。因此后续 20 seed 验收以 stochastic 为准。

## C.7 稳定性与失败模式

- 三类失败模式都已区分并实际出现过：`clip_end`（全部）、`physical_fall`（仅模型 1.0.6，D 报告）、
  `reference_deviation`（官方随机起点回放里出现，B 报告）。本次 20 seed 中没有
  `numeric_anomaly` / `reset_or_state_override`。
- 参考偏差在 stochastic 固定起点下从未触发（handler 检查在结束时均为 False）。
- 20 seed 同进程顺序执行，峰值 RSS 2.5–4.3 GB，无 swap 压力；总耗时约 4 分钟/组。
